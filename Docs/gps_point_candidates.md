# GPS point 候補（大会公式値受領前）

## 目的と扱い

この文書は、大会からGPS pointの公式緯度経度が提示されるまでの間に、
シミュレーション・経路設計・現地の下見で共通に使う**仮の候補値**をまとめるものです。
ここに示す点は大会公式値でも、航行可能域を保証する値でもありません。

基準には、共有された地図地点を用います。

- 地図地点: <https://www.google.com/maps/search/?api=1&query=63.4420936,10.4242793>
- 緯度・経度（WGS84、十進度）: **63.4420936, 10.4242793**
- ローカル地図座標: この地点を各Taskの候補コースの `(x, y) = (0, 0)` とする
- 軸: `x` は東、`y` は北、単位はm

各Taskの開始直後の進行方位は、次の地点へ向かう方向に合わせる。

- 目標地点: <https://www.google.com/maps/search/?api=1&query=63.4416044,10.4238816>
- 緯度・経度: **63.4416044, 10.4238816**
- 基準点から見た方位: **約200.0°**（真北基準、南から西へ約20.0°）
- 基準点からの距離: 約58m

公式の水域境界、スタート／ゴールの位置、ブイ・ドックの位置、および安全距離が分かった時点で、
この候補を必ず置き換えること。

## 換算方法

基準点 `(lat0, lon0)` から近距離の候補点を置く際は、以下の近似を使う。

```text
lat [deg] = lat0 + y / 111320
lon [deg] = lon0 + x / (111320 * cos(lat0))
```

この文書の値は上式で計算した。会場規模（数十m）では、コース案の作成用として十分な精度である。

## Task 1 候補

Task 1の公式図にあるGPS 1〜4の並びに合わせた仮配置である。
上段はGPS 1→中間waypoint 1.1〜1.10→GPS 2、下段はGPS 3→カーディナルマーク群→GPS 4とする。
上段の開始方向（GPS 1からGPS 2側）は目標地点の方位に合わせる。下段は公式図どおり逆向きに進む。
GPS 1での開始はRemote Control、主任審判の合図後にAutonomous Modeへ切替える前提である。
前半を完了できない場合は、公式説明どおりGPS 3から後半を開始する候補としている。

```text
GPS 1  →  waypoint 1.1 … 1.10（蛇行）  →  GPS 2
  │                  約35 m                   │
GPS 4  ←  cardinal marks / 3.3 … 3.1   ←  GPS 3
```

## 公式値受領後の更新手順

1. 公式の緯度経度を `gps_points` にそのまま記録する。
2. Taskごとに選んだ原点から、全点の `x`, `y` を同一の投影・基準で計算する。
3. 実機の `map` 原点、`navsat_transform_node` のdatum、経路設定の原点を一致させる。
4. 現地で水面境界・障害物・安全マージンを確認し、経路とブイ／ドックの位置を更新する。
