# CODEX_GLOSSARY.md

Use these abbreviations in handoffs and notes.

- WS: workspace
- PKG: ROS 2 package
- PS: `colcon build --packages-select`
- FB: full workspace build
- FT: full workspace test
- RL: `ros2 launch`
- HW: hardware
- SIM: simulation
- TF: transform tree
- NP: Nav2 parameters
- CM: costmap
- CTRL: controller_server
- PLAN: planner_server
- BT: behavior tree
- ODOM: odometry frame
- ESTOP: emergency stop
- HOF: handoff
